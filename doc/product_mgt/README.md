# Historical design artifacts

The seven Word files in this directory form the retained, retrospective historical design and iteration sequence. They are not a reconstruction of Git history and are not asserted to correspond one-to-one with commits made before the repository was published.

- `v6-20260710` is the direct July baseline for the current iteration.
- `v7-20260825` is the August iteration aligned with public release 1.0.0. It documents the continuation of v6 together with implementation, security, correctness, testing, documentation and evidence-boundary updates.
- Earlier files remain legacy design artifacts and are not rewritten by v7.

- Their file names record an intended version sequence.
- Because Git was introduced only for the completed project's public release, these artifacts must not be presented as evidence of earlier Git commits.
- Embedded Office creator, modification and template metadata may reflect earlier software, templates or collaborators; it must not be used as independent proof of authorship or exact dates.
- Anyone presenting these files in an application should identify their own contribution and any collaborators accurately.
- These files do not by themselves contain Shanghai site records, personal information or measured impact results; operational status is stated by the maintainer in the current public documentation.

The current public implementation and evidence boundary are documented in the repository root `README.md` and `EVIDENCE_AND_LIMITATIONS.md`. When a historical document conflicts with those current files, the current public documentation takes precedence.
