## 1.0.0 — 2026-08-25

这是从私人工作副本整理出的干净公开发布快照。

### 安全

- 将无盐 SHA-256 密码存储替换为 bcrypt。
- 删除硬编码管理员密码；初始化时读取环境变量或生成一次性密码。
- 生产环境缺少 `SECRET_KEY` 时拒绝启动。
- 默认仅监听 `127.0.0.1`，CORS 默认仅允许本机来源。
- 所有用户、车位、记录、预约、配置和规则调度接口要求管理员登录。
- 管理员注册改为仅超级管理员可操作。
- 修改密码改用请求体，避免密码出现在 URL 查询参数中。
- 前端表格转义数据，降低存储型 XSS 风险。

### 正确性与可测试性

- 修复静态 API 路径被动态 ID 路由拦截的问题。
- 修复枚举大小写导致规则分配找不到可用车位的问题。
- 修复指定车位分配忽略目标 ID 和积分兑换重复扣分的问题。
- 将随机流量输出替换为确定性历史基线；无数据时返回零值和零覆盖度。
- 增加 pytest 自动测试和 GitHub Actions。
- 移除与精简后依赖不一致的旧锁文件；2026-08-27 公开复用增强中已重新生成并验证当前 `uv.lock`。

### 公开说明

- 增加 MIT `LICENSE`、安全政策、贡献指南、发布说明和证据边界。
- 统一公开版本号为 1.0.0。
- 增加 `园区停车场系统设计v7-20260825.docx`，将 8 月公开版明确记录为在 7 月 v6 基础上的设计迭代。
- 删除未经基准测试支持的延迟、并发和百分比提升声明。
- 根据项目维护者确认，将项目定位统一为“上海实际使用基础上的开放复用版”。
- 明确公开初始化数据与上海现场个人信息、凭据和实时业务数据的区分。
- 增加 `DEPLOYMENT.md`：记录 2026 年 3 月开始在上海企业园区停车场使用、3 名管理员、286 个车位、全部公开版应用模块投入使用，以及企业园区管理办公室可确认实际使用情况；后续更新进一步说明系统投入使用后继续迭代，并把代码一致性限定为当前状态。
