# 当前实现说明

## 实际使用情况

- 2026 年 3 月在上海一处企业园区停车场开始实际使用；投入使用后继续迭代。
- 现场有 3 名管理员，管理 286 个车位，公开版所包含的应用模块均已使用。
- 截至当前公开快照，当前公开仓库与当前现场应用使用相同的应用源代码；这不表示 8 月版本在 3 月时已以完全相同形态存在。
- 实际使用情况可由该企业园区管理办公室确认；企业名称、具体地址、联系人和现场数据不在公开仓库披露。
- 详细范围见根目录 `DEPLOYMENT.md`。

## 已实现

- FastAPI 后端与原生 JavaScript 单页界面。
- SQLAlchemy/SQLite 数据模型，包含管理员、用户、车位、停车记录、预约、积分和配置。
- JWT 管理员认证；所有管理 API 均要求登录。
- 超级管理员创建和管理其他管理员。
- bcrypt 加盐密码哈希、环境变量密钥和受限 CORS。
- 车位尺寸、无障碍需求和楼层偏好的透明规则评分。
- 历史小时计数基线、长时停车阈值和容量占用率提示。
- 自动化 API 与运维工具测试、依赖锁定、公开包检查和 GitHub Actions。
- 环境变量模板、Docker/Compose 启动基线、健康检查和 SQLite 一致性备份工具。
- 可通过 GitHub Actions 发布的英文 GitHub Pages 项目介绍页。

## 公开版范围与现场差异

- 公开仓库未包含上海现场的相机、道闸、支付、车牌识别、凭据和实时业务数据接入配置。
- 没有训练机器学习模型；流量功能是确定性历史基线。
- 公开仓库未收录现场个人资料、原始前后对比数据或运营效果测量包。
- 没有完成延迟、吞吐量或并发用户基准测试。
- 公开版默认使用 SQLite，并提供本地配置、容器基线和 SQLite 备份工具；上海现场或其他部署仍应使用各自的密钥、审计、集中监控、异地备份、恢复演练和硬件配置。

## 数据

286 是经项目维护者确认的现场车位规模。公开初始化脚本保留相同的总量，但使用示例车位编号和生成用户；这些初始化数据不对应真实个人，也不包含上海现场业务记录。

## 接口

运行系统后，以 `/docs` 自动生成的 OpenAPI 页面为当前接口事实来源。除 `/health`、登录接口和静态前端外，管理接口都需要 Bearer Token。
