# Public release note

This folder was prepared as a clean public-release snapshot on 2026-08-25 from a private working copy.

The public-reuse packaging, example-data labeling, timeline wording, tests and English project-page workflow were further strengthened on 2026-08-27 without changing the core parking business behavior.

Git was introduced only after the initial system had been completed and this public package was being prepared. Accordingly, the repository begins with the current-date commit `chore: publish completed system as public release snapshot v1.0.0` and the `v1.0.0` tag. It does not reconstruct, backdate or imply an earlier Git development history.

- The January-August Word files and changelog are retrospective historical design and iteration records, not evidence of corresponding Git commits.
- No removed draft, generated evaluation material or local database is included.
- The project maintainer confirms that operational use began in March 2026 at a Shanghai corporate industrial park parking facility, with 3 administrators and 286 managed spaces. The running system continued to be iterated after launch. As of this public snapshot, the current public application source and the current on-site application source match; this does not mean the August snapshot existed unchanged in March. All public-edition application modules are used on site, and the corporate industrial park management office can confirm the deployment. See `DEPLOYMENT.md`.
- Historical artifacts remain design records; the company name, site address, personal information, credentials, live database and original operational records are not included in this public snapshot.
- All changes after this first publication are recorded with their real dates as focused commits, tags and Releases.

This separation keeps the downloadable repository understandable without creating a false Git timeline.
